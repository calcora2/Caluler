About this Time Calculator

Choose a start time and an end time to calculate elapsed hours and minutes. When the end time is earlier than the start time, the calculator treats the end time as occurring on the following day.

How to use

  1. Choose the start time.
  2. Choose the end time.
  3. Select Calculate Time and review the elapsed duration.

Calculation method & worked example

The calculator converts both times to minutes after midnight and subtracts the start from the end. If the end is earlier, it adds one day. Example: 10:30 PM to 2:15 AM is 3 hours and 45 minutes.
