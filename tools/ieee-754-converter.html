About the IEEE 754 Float32 Converter

IEEE 754 single-precision floating point uses 32 bits split into one sign bit, eight exponent bits, and 23 fraction bits. Finite decimal values may be rounded to the nearest representable Float32 number.

IEEE 754 Float32 stores a single-precision floating-point value as 1 sign bit, 8 exponent bits and 23 fraction bits. Inspect the bit fields and hexadecimal representation when learning floating-point encoding or debugging binary data.

Formula & method

Float32 layout: 1 sign bit + 8 exponent bits + 23 fraction bits = 32 bits

How to use

  1. Use the fields labelled: Mode, Decimal number or bit pattern. Enter valid values or choose required options, following the units and optional-field notes shown beside each field.
  2. Select Convert to run IEEE 754 Float32 Converter and display the result.
  3. Check the result and units, then compare the output with the formula or method notes before applying the result.

Important note

This tool specifically handles 32-bit Float32. It is not a 64-bit double-precision converter. IEEE 754 bit patterns may represent zero, subnormal values, infinity, or NaN.

This browser-based tool does not save your input to an account. Verify results before using them in critical engineering, programming, or other high-stakes work.

Frequently Asked Questions

Why can a decimal value change after conversion?

Some decimal fractions cannot be represented exactly with a finite binary fraction field, so the value is rounded to the nearest Float32 value.

How do I decode a pattern?

Choose decode mode and enter exactly 32 binary bits or 8 hexadecimal digits.

Can it show the individual fields?

Yes. The output contains the full bit pattern, sign, exponent, fraction and decoded value.
