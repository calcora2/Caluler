About the One Rep Max Calculator

The Epley equation estimates a theoretical one-repetition maximum from a set completed for multiple repetitions. Accuracy varies with repetitions, lifting technique and fatigue; the estimate does not determine whether attempting a maximum lift is safe.

How to use

  1. Enter the lifted weight in kilograms and the number of completed repetitions in the set.
  2. Calculate the estimated one-repetition maximum using the displayed method.
  3. Treat the result as a prediction, not a performance guarantee. Use sound technique and appropriate supervision when strength-testing.

Formula and worked example

This tool uses the Epley estimate: one-rep maximum ≈ lifted weight × (1 + repetitions ÷ 30). For 80 kg lifted for 8 repetitions, the estimate is 80 × (1 + 8 ÷ 30) ≈ 101.3 kg.

This is a prediction, not a measured maximum. Estimates become less reliable at higher repetition counts and should not encourage unsafe maximal lifting.

Frequently Asked Questions

Which equation does this calculator use?

It uses an Epley-style estimate: lifted weight multiplied by one plus repetitions divided by 30. One repetition returns the lifted weight itself.

How should I interpret the estimate?

Technique, fatigue, exercise type and individual response can change the actual maximum. This is not a direct strength test.

Which inputs are accepted?

Enter lifted weight from 1–1,000 kg and whole-number repetitions from 1–30.
