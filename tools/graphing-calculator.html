About the Graphing Calculator

This free graphing calculator draws explicit functions of the form y = f(x). Plot several equations together to compare their shape and behavior. The graph is generated in your browser from the expressions you enter.

How to use

  1. Enter one or more equations using x as the variable, for example x^2 - 4 or sin(x).
  2. Set the x and y ranges you want to see, then select Plot functions.
  3. Use zoom controls to change the viewing window, or enter an x-value to evaluate the plotted functions.

Supported functions

Use sin, cos, tan, asin, acos, atan, sqrt, abs, ln, log, exp, floor, ceil and round. Use pi or e for the constants π and Euler’s number. Exponents use ^; multiplication can be written as 2*x or 2x.

Limitations

This tool plots explicit functions y = f(x), not implicit equations or parametric curves. Trigonometric functions use radians. Discontinuities and values outside the selected y-range may not appear as continuous lines.
