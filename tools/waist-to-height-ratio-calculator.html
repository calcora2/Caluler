Waist compared with height

Waist and height must use the same unit. The ratio is a screening indicator, not a medical diagnosis.

What the ratio means

Waist-to-height ratio (WHtR) compares waist circumference with height. Measure waist consistently and use the same units for both values.

Waist ÷ Height → Ratio

Formula and worked example

WHtR = waist circumference ÷ height. For a waist of 85 cm and a height of 170 cm, WHtR = 85 ÷ 170 = 0.50.

Adult interpretation

NICE describes 0.40–0.49 as a range indicating no increased central-adiposity risk, 0.50–0.59 as increased, and 0.60 or higher as high. This is a screening indicator, not a diagnosis. NICE recommends using waist-to-height ratio alongside BMI for adults with BMI below 35 kg/m².

Frequently Asked Questions

How is waist-to-height ratio calculated?

Divide waist circumference by height using the same unit. This calculator uses centimetres for both inputs.

What do the adult reference bands mean?

The page shows commonly cited adult reference bands. They are screening guidance, not a diagnosis, and should be interpreted with other information.

Does this replace BMI or professional advice?

No. Waist-to-height ratio is one screening measure. The appropriate interpretation depends on individual circumstances.
