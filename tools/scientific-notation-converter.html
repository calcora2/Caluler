About this Scientific Notation Converter

Convert ordinary numbers into scientific notation or convert scientific notation back into ordinary decimal form. Scientific notation is useful for very large and very small numbers. You can choose automatic precision or specify between 1 and 15 significant figures.

How to use

  1. Enter an ordinary number or scientific notation, for example 1200000, 0.00045, or 1.2e6.
  2. Choose whether to convert to scientific notation or back to an ordinary number.
  3. Select automatic precision or the number of significant figures you need.
  4. Press Calculate to view the result and explanation. Use Copy Result to copy the answer.

Formula and worked examples

Scientific notation writes a non-zero number as a coefficient multiplied by ten raised to an integer exponent. For example, 1200000 = 1.2 × 10^6, while 0.00045 = 4.5 × 10^-4. A positive exponent represents a large number; a negative exponent represents a small decimal.

Significant figures

Significant figures control the precision displayed in the result. Automatic precision uses JavaScript's shortest round-trip representation. Selecting a specific number of significant figures rounds the result to that precision.

Important note

This tool uses JavaScript's standard finite-number precision. Extremely precise values may be rounded by the browser, so verify calculations that require arbitrary-precision arithmetic with a suitable specialist tool.
