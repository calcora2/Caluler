About the Number System Converter

A positional number is represented by digits multiplied by powers of its base. This tool supports signed whole integers, exact conversion between supported bases, and arithmetic with BigInt to avoid ordinary JavaScript integer rounding.

Use this number system converter to change whole integers between binary, octal, decimal, hexadecimal and other supported bases. It also supports exact integer arithmetic, making it useful for computer science exercises and debugging numeric representations.

Formula & method

value = Σ (digit × base^position)

How to use

  1. Use the fields labelled: First integer, Second integer (for arithmetic), Input base, Output base, Operation. Enter valid values or choose required options, following the units and optional-field notes shown beside each field.
  2. Select Calculate to run Number System Converter and display the result.
  3. Check the result and units, then compare the output with the formula or method notes before applying the result.

Important note

Fractions are not supported in this integer converter. Choose a base from 2 to 36. The Add, Subtract, and Multiply operations interpret both operands in the selected input base.

This browser-based tool does not save your input to an account. Verify results before using them in critical engineering, programming, or other high-stakes work.

Frequently Asked Questions

Which bases are supported?

Binary, octal, decimal, hexadecimal, and any base from 2 through 36 using digits 0–9 and letters A–Z.

Can I enter prefixes?

Optional 0b, 0o, and 0x prefixes are accepted for binary, octal, and hexadecimal input.

Are large integers rounded?

No. Conversion and integer arithmetic use BigInt for exact integer results.
