About the Binary Fraction Converter

Digits after the binary point represent descending powers of two: 2⁻¹, 2⁻², 2⁻³ and so on. Decimal-to-binary output is an approximation for fractions whose binary expansion does not terminate.

A binary fraction uses powers of two to the right of the binary point, such as 101.101₂ = 5.625₁₀. Convert between binary and decimal fractions and review how fractional-bit precision affects non-terminating results.

Diagram and example

Formula & method

101.101₂ = 1×2² + 0×2¹ + 1×2⁰ + 1×2⁻¹ + 0×2⁻² + 1×2⁻³

How to use

  1. Use the fields labelled: Conversion direction, Value, Fractional-bit precision. Enter valid values or choose required options, following the units and optional-field notes shown beside each field.
  2. Select Convert to run Binary Fraction Converter and display the result.
  3. Check the result and units, then compare the output with the formula or method notes before applying the result.

Important note

Binary-to-decimal accepts up to 53 integer bits and finite binary fractions. Decimal-to-binary uses JavaScript floating-point arithmetic and displays the chosen precision and truncation note.

This browser-based tool does not save your input to an account. Verify results before using them in critical engineering, programming, or other high-stakes work.

Frequently Asked Questions

Why does some output end with an ellipsis?

It means there are remaining binary fractional digits beyond the selected precision.

Is 101.101 exact?

Yes, this finite binary fraction converts to the exact decimal value 5.625.

Can I choose how many bits to display?

Yes. Select 8, 16, 24 or 32 fractional bits.
